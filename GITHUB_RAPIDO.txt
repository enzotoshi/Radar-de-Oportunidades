OPÇÃO 2: MANUAL
===============

Se preferir fazer manualmente, abra PowerShell e execute:

# 1. Configurar Git (primeira vez)
git config --global user.name "Seu Nome"
git config --global user.email "seu@email.com"

# 2. Inicializar repositório
cd "c:\Users\25011991\Downloads\Radar-de-Oportunidades-main"
git init

# 3. Adicionar arquivos
git add .

# 4. Criar commit
git commit -m "Initial commit"

# 5. Conectar com GitHub (substitua pela SUA URL)
git remote add origin https://github.com/SEU-USUARIO/radar-de-oportunidades.git
git branch -M main

# 6. Enviar para GitHub
git push -u origin main

5. Use o token como senha
