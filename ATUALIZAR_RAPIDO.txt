OPÇÃO 1: AUTOMÁTICO (MAIS FÁCIL) ⭐
====================================

📂 Duplo clique em: atualizar-github.cmd

O script vai:
✅ Adicionar todas as mudanças
✅ Criar commit automaticamente
✅ Enviar para o GitHub
✅ Mostrar resultado

═══════════════════════════════════════════════════════════════

OPÇÃO 2: MANUAL (3 COMANDOS)
=============================

Abra PowerShell nesta pasta e execute:

# 1. Adicionar mudanças
git add .

# 2. Criar commit
git commit -m "Descrição da mudança"

# 3. Enviar
git push

PRONTO! ✅

🆘 SE DER ERRO
==============

❌ "Permission denied"
→ Use Personal Access Token:
  https://github.com/settings/tokens

❌ "No changes"
→ Você já está atualizado!

❌ "Conflict"
→ Execute: git pull
→ Depois: git push

❌ "Remote repository not found"
→ Verifique se o repositório existe no GitHub
→ Execute: git remote -v
