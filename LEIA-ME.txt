🚀 COMO INICIAR
═══════════════════════════════════════════════════════════════

1️⃣  PRIMEIRA VEZ - Instalar dependências:

PowerShell:
cd backend
pip install -r requirements.txt

cd ../frontend  
npm install

⏱️  Aguarde 5-10 minutos

─────────────────────────────────────────────────────────────

2️⃣  INICIAR O SISTEMA:

Opção A - AUTOMÁTICO (mais fácil):
📂 Duplo clique em: start.cmd
→ Escolha opção 3

Opção B - MANUAL (2 terminais):

Terminal 1 (Backend):
cd backend
python -m uvicorn main:app --reload --port 8000

Terminal 2 (Frontend):
cd frontend
npm run dev

─────────────────────────────────────────────────────────────

3️⃣  ACESSAR:

🌐 Frontend: http://localhost:3000
🔧 Backend: http://localhost:8000
